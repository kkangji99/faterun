# 운명 피하기 — 기획 v0.2 (오행 가위바위보 러너)

> 생일만 넣으면 내 팔자대로 달린다.
> 사주는 **양념**이다. 사주를 몰라도 3초 안에 이해되고 웃겨야 한다.

## 한 줄 규칙
**다섯 모양이 가위바위보처럼 물고 물린다.** 다가오는 장애물을 **이기는 모양**으로 변신해서 부순다.

```
🌱나무 > 🪨흙 > 💧물 > 🔥불 > ⚔️쇠 > 🌱나무
```

## 조작 (버튼 2개)
| 입력 | 동작 |
|---|---|
| 왼쪽 탭 / Z | **변신**: 나무 → 불 → 흙 → 쇠 → 물 → 나무 (순서대로 돌아감) |
| 오른쪽 탭 / Space | **점프**: 작은 장애물 넘기 |

## 부딪혔을 때
| 내 모양 vs 장애물 | 결과 |
|---|---|
| 이기는 모양 | **박살!** 점수 + 콤보 + 럭키 게이지. 본캐 모양으로 부수면 점수 ×2 |
| 같은 모양 | 같은 편이라 **스르륵 통과** |
| 지는 모양 | **천적!** 하트 -2 |
| 그 외 | 아야! 하트 -1 |

- 하트 3개로 시작 (최대 5)
- 콤보 5마다 점수 배율 +0.5 (최대 ×3)
- 럭키 게이지가 차거나 **럭키템(네잎클로버)**을 먹으면 **럭키타임** 5초: 전부 부수고 더 빨라짐
- **짝퉁 럭키템(세잎, 삐뚤)**은 게이지 0 + 점수 -300. 진짜를 알아보는 눈이 실력

## 장애물 리듬
완전 랜덤 대신 덩어리 단위로 나온다. 거리가 늘수록 체인이 길어지고 간격이 좁아진다.

| 덩어리 | 내용 |
|---|---|
| 하나 | 큰 벽 1개 |
| 쌍둥이 | 같은 벽 2개. 한 번 맞추면 연속 격파 |
| 체인 | 2~4개. **한 번씩만 탭하면 다음 벽을 이기는 모양**이 되도록 배치된 리듬 구간 |
| 허들 | 작은 장애물 2~3개 + 위에 코인 |
| 섞기 | 벽 뒤에 바로 허들 |
| 쉬어가기 | 코인 줄 |

- 초보 힌트: 처음 12개를 부술 때까지, 그리고 지고 난 뒤 8초 동안 벽 위 말풍선에 "이걸로 부숴!" 모양이 뜬다
- 럭키템은 약 400m마다 보장

## 사주가 하는 일 (양념)
| 게임에서 부르는 말 | 사주 원래 말 | 효과 |
|---|---|---|
| **본캐** | 일간 | 시작 모양 + 캐릭터. 본캐로 부수면 점수 ×2 |
| **내 천적** | 나를 극하는 오행 | 본캐를 이기는 모양. 카드에 표시 |
| **내 귀인** | 나를 생하는 오행 | 카드에 표시 |
| **럭키템** | 용신 | 네잎클로버 가운데 색 |
| **짝퉁 럭키템** | 기신 | 세잎클로버 가운데 색 |
| **팔자 스킬** | 신살 | 아래 표 |
| **오늘의 운세** | 일진 | 오늘 많이 나오는 모양 + 하루 효과 |
| **팔자 한 줄 요약** | 오행 과다/부재 | "불이 넘치고 물이 텅 빈, 방랑벽 있는 불꽃 폭주족" |

### 본캐 5종
| 모양 | 캐릭터 | 한 줄 |
|---|---|---|
| 🌱 나무 | 고집 센 새싹 | 꺾일지언정 굽히지 않는 타입 |
| 🔥 불 | 불꽃 폭주족 | 일단 지르고 수습은 나중에 하는 타입 |
| 🪨 흙 | 듬직한 돌하르방 | 움직이긴 싫지만 믿음직한 타입 |
| ⚔️ 쇠 | 칼같은 로봇 | 맺고 끊음이 확실한 타입 |
| 💧 물 | 말랑 슬라임 | 어디든 스며드는 타입 |

### 팔자 스킬
| 스킬 | (원래 말) | 효과 |
|---|---|---|
| 🧳 방랑벽 | 역마살 | 속도 ×1.3, 점수 ×1.5 |
| 💘 인기쟁이 | 도화살 | 코인 자석, 가끔 장애물이 반해서 비켜줌 |
| 🧘 해탈 도사 | 화개살 | 하트가 다 떨어져도 1회 부활 |
| 🐯 돌진 호랑이 | 백호살 | 지는 모양으로 부딪혀도 30% 확률로 박살 |
| 🍀 무난한 팔자 | 신살 없음 | 하트 +1 |

### 오늘의 운세
오늘 날짜의 오행이 **2배 자주** 나오고, 내 본캐와의 사이에 따라 하루 효과가 붙는다.

| 오늘 | 효과 | 별점 |
|---|---|---|
| 귀인이 돕는 날 | 시작 하트 +1 | ★★★★★ |
| 재물운 터지는 날 | 코인 ×2 | ★★★★☆ |
| 끼 폭발하는 날 | 럭키타임 +2초 | ★★★★☆ |
| 라이벌 출몰의 날 | 같은 모양이 자주 나옴 (통과 찬스) | ★★★☆☆ |
| 천적 출몰의 날 | 천적이 자주 나옴, 대신 점수 ×1.5 | ★★☆☆☆ |

## 결과 카드 (1080×1920)
1. 제목 · 날짜 · 오늘 운세 별점
2. 본캐 그림 + "나는 불꽃 폭주족" + 팔자 한 줄 요약
3. 내 천적 / 내 귀인 / 럭키템
4. 팔자 스킬 칩
5. **사인(死因)**: "물폭탄한테 불 모양으로 돌진했다가 꺼져버림"
6. **오늘의 액땜** %: 거리 40 + 부순 수 30 + 최고 콤보 20 + 럭키타임 10 (최대 99)
7. 기록: 달린 거리 · 부순 장애물 · 최고 콤보
8. 버튼: 다시 달리기 · 이미지 저장 · 공유하기 (저장 이미지에는 버튼 대신 사주 원문 한 줄 + 주소)

