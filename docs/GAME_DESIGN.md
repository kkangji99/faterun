# 《운명 피하기: 내 사주대로 달린다》 게임 기획서 v0.1

> 생년월일시를 넣으면 사주(만세력)가 캐릭터·스탯·장애물·기믹을 바꾸는 2D 캐주얼 러너.
> 목표 감정: **"내 팔자가 진짜 난이도를 정한다"** 는 몰입감 + B급 드립의 쾌감 + 결과 카드 공유 욕구.
> 모든 수치는 `src/game/tables.js` 한 곳에 있다. 이 문서의 표 = 그 파일의 값.

---

## 0. 한눈에 보기

| 항목 | 내용 |
|---|---|
| 플랫폼 | 웹 브라우저(PC/모바일 반응형), Phaser 3 + Canvas 2D |
| 조작 | 2버튼 — **점프**(↑/Space, 화면 왼쪽 탭) / **슬라이딩**(↓, 화면 오른쪽 홀드) |
| 한 판 길이 | 1~3분 (3분에 걸쳐 속도 최대 2배까지 상승) |
| 코어 루프 | 생년월일시 입력 → 캐릭터·오늘의 운세 공개 → 달리기 → 사망 → 결과 카드 공유 → "한 판 더(액땜)" |
| 재방문 동기 | **오늘의 일진**이 매일 바뀌어 같은 캐릭터라도 매일 다른 버프/디버프 |

```
[입력] 생년월일시 ─▶ [만세력] 4기둥 8글자 ─▶ [분석] 일간·오행 분포·신강약·용신·신살
                                                   │
[오늘 날짜] ─▶ 오늘 일진 ─▶ 합/충/생극 판정 ──────────┤
                                                   ▼
                          캐릭터 + 스탯 + modifier 묶음(mods) + 장애물 출현 가중치
                                                   ▼
                     RunScene: 충돌 판정(combat.js) ─▶ 사망 ─▶ 결과 카드(resultCard.js)
```

## 1. 사주 연동 시스템

### 1-1. 일간(본원)별 캐릭터

일간 = 태어난 날의 천간. 캐릭터의 "본체"를 결정한다.

| 일간 | 캐릭터 | 비주얼 콘셉트 | HP | 속도 | 점프 | 고유 패시브 |
|---|---|---|---|---|---|---|
| 木 (甲乙) | 죽순 닌자 **"뚝심이"** | 대나무 삿갓 + 초록 두건, 달릴수록 머리에 새싹이 자람 | 100 | 1.00 | 1.10 | **쑥쑥 성장** — 30초 생존마다 최대 HP +5, 즉시 5 회복 (최대 +30) |
| 火 (丙丁) | 불꽃 폭주족 **"화끈이"** | 불타는 모히칸 + 가죽재킷, 발자국마다 불똥 | 80 | 1.15 | 1.00 | **불붙은 콤보** — 코인 20콤보마다 3초 불꽃대시(장애물 파괴·무적) |
| 土 (戊己) | 돌하르방 탱커 **"묵직이"** | 미니 돌하르방, 달리면 쿵쿵 흙먼지 | 140 | 0.90 | 0.90 | **바위 피부** — 피격 1회 무효 보호막, 소모 후 20초마다 재생성 |
| 金 (庚辛) | 칼각 로봇 **"쇠돌이"** | 크롬 바디 + 한쪽 눈 레이저 조준경 | 90 | 1.05 | 1.00 | **칼같은 회피** — 장애물이 닿기 0.15초 이내에 회피 동작 → 0.6초 슬로모 + 저스트 점수 ×3 |
| 水 (壬癸) | 물방울 슬라임 **"말랑이"** | 반투명 파란 슬라임, 슬라이딩 시 납작하게 퍼짐 | 100 | 1.00 | 1.00 | **물 흐르듯** — 2단 점프(물수제비), 피격 무적 +50%, 슬라이딩 판정 더 납작 |

- 양간(甲丙戊庚壬)/음간(乙丁己辛癸)은 **스킨 색 변주**(진한/연한 톤)로만 구분 — 스탯 차이 없음(밸런스 단순화).
- 공통 기본값: 자석 반경 40px, 피격 무적 0.8초, 점프 1회.

### 1-2. 신살(神煞) 패시브 기믹

판정 기준: **년지·일지**의 삼합 그룹으로 나머지 지지에서 역마/도화/화개를 찾고, 백호는 기둥 자체(백호대살 7주)로 판정. 여러 개면 **전부 중첩**.

| 신살 | 판정 | 게임 효과 | 밈 포인트 |
|---|---|---|---|
| **역마살** 🐎 | 申子辰→寅, 寅午戌→申, 巳酉丑→亥, 亥卯未→巳 | 기본 속도 **×1.5**, 점수 **×1.8**, 받는 피해 ×1.2. 30초마다 배경 국가 랜덤 전환(서울→파리→사막…) | "팔자에 없는 출장을 뛴다" |
| **도화살** 🌸 | 申子辰→酉, 寅午戌→卯, 巳酉丑→午, 亥卯未→子 | 자석 반경 **+140px(=180px)**. 장애물 5%가 반해서 ♥ 날리며 **스스로 비켜줌**. 대신 코인 10%가 "러브레터(0점)"로 바뀜 | "장애물도 나한테 반함" |
| **화개살** 🪷 | 申子辰→辰, 寅午戌→戌, 巳酉丑→丑, 亥卯未→未 | HP 0 시 **1회 윤회 부활**(HP 30%, 2초 무적). 피버 충전 +30%. 속세 무관심으로 코인 가치 -20% | "해탈했지만 돈은 못 모음" |
| **백호살** 🐯 | 甲辰·乙未·丙戌·丁丑·戊辰·壬戌·癸丑 기둥 보유 | 충돌 시 **30% 확률로 장애물 박살**(무피해 + 500점). 대신 받는 피해 ×1.3 | "피하지 말고 박아라" |

> ⚠️ 밸런스 주의: 역마(×1.2) + 백호(×1.3) 중첩 시 상극 장애물 1회 = 20×2×1.56 ≈ **62 데미지**.
> 火 일간(HP 80)은 상극 2방에 사망. 의도된 하이리스크지만, 튜토리얼 문구로 "당신은 **유리대포형 팔자**입니다" 경고 필수.

### 1-3. 오행 불균형 보상 (과다 ≥3 / 부재 0)

8글자(시주 모르면 6글자)를 **천간 + 지지 본기** 기준으로 센다.

| 오행 | 과다(3개 이상) | 부재(0개) |
|---|---|---|
| 木 | **정글의 법칙** — 木 장애물 출현 +50%, 점프력 +10% | **성장판 닫힘** — 점프 체공 -5% |
| 火 | **과열 경보** — 속도 +10%, 피버 지속 +2초, 20초마다 1초 아지랑이 화면 | **열정 품절** — 피버 지속 -1초 |
| 土 | **고집불통** — 속도저하 상태이상 면역, 점프력 -10% | **뿌리 없는 러너** — 착지 경직 +0.05초 |
| 金 | **금속탐지기** — 코인 가치 +20%, 같은 오행(비겁) 장애물 피해 -30%(동족 할인) | **결단력 가출** — 저스트 회피 판정 -30% |
| 水 | **범람** — 슬라이딩 중 낮은 장애물을 물보라로 통과(쿨다운 4초), 25초마다 2초 화면 물결 | **건조주의보** — 피격 무적시간 -20% |

- **결핍 보상(공통)**: 부재 오행의 아이템을 먹으면 효과 **×2** + "득템!" 연출. → "없는 걸 채워주는" 사주 상담 서사를 게임 문법으로 번역.

## 2. 상생상극 장애물 · 아이템

### 2-1. 오행별 장애물

| 장애물 오행 | 외형 | 상극 시(이 오행이 내 일간을 극할 때) 상태이상 |
|---|---|---|
| 金 | 칼날·작두·가위 | 木 일간 → **벌목당함**: 3초간 초당 HP -3 (출혈 DoT) |
| 水 | 물폭탄·파도 | 火 일간 → **불씨 꺼짐**: 2초간 속도 -30% |
| 木 | 가시덩굴·죽창 | 土 일간 → **뿌리 박힘**: 1.5초간 점프 불가 |
| 火 | 불기둥·화염방사 | 金 일간 → **녹아내림**: 1.5초간 점프/슬라이드 **버튼 반전** |
| 土 | 바위·흙더미 | 水 일간 → **흙탕물 샤워**: 2초간 화면 60% 진흙 가림 |

- 형태 2종: **낮은 장애물**(점프로 회피, 크기 1.2) / **높은 장애물**(머리 위, 슬라이딩으로 회피, 크기 1.0). 비율 65:35.
  높은 장애물은 서 있으면 머리에 20px 걸리고, 슬라이딩하면 20px 여유로 통과한다.
- 출현 오행은 기본 균등. `오늘 시련의 날`이면 상극 오행 가중치 ×1.3, `木 과다`면 木 +0.5.

### 2-2. 관계별 충돌 배율

| 장애물 오행과 내 일간의 관계 | 이름 | 피해 배율 | 추가 |
|---|---|---|---|
| 나를 극함 | **상극(관성)** | **×2.0** | 상태이상 발동, 액땜 통계에 "상극 피격" 기록 |
| 내가 생함 | 식상(설기) | ×1.2 | 기가 빨림 |
| 같은 오행 | 비겁 | ×1.0 | 金 과다면 ×0.7 |
| 나를 생함 | 인성 | ×0.7 | 살살 부딪힘 |
| 내가 극함 | 재성 | ×0.5 | **20% 확률로 장애물 파괴**(+200점) |

### 2-3. 아이템

| 아이템 | 조건 | 효과 |
|---|---|---|
| 복(福) 코인 | 기본 | +10 × 코인배율, 콤보 +1 |
| **상생 구슬** | 나를 생하는 오행 | **HP +15, 피버 게이지 +20 (스파크 연출)** |
| 비겁 구슬 | 같은 오행 | +300점, 게이지 +10 |
| 일반 구슬 | 그 외 오행 | +100점, 게이지 +5 |
| **용신 구슬**(금테) | 내 용신 오행, 출현 2%/스폰(천간합일 ×2), **45초 보장** | **용신버스터** 발동 |
| 기신 구슬(가짜 금테) | 용신을 극하는 오행, 3% | 게이지 -30, 점수 -200. "기신이었다…" |
| 러브레터 | 도화살 전용, 코인 대체 10% | 0점 (자석이 쓸데없이 끌어옴) |

### 2-4. 피버 & 용신버스터

| 구분 | 발동 | 지속 | 효과 |
|---|---|---|---|
| 일반 피버 | 게이지 100 | 4초 (火 과다 +2 / 無火 -1) | 무적, 부딪히는 장애물 파괴 +150점 |
| **용신버스터** | 용신 구슬 획득 | **6초** | **화면 내 장애물 즉시 싹쓸이**(각 +300점), 무적, 속도 ×1.6, 상태이상 해제, 화면 금빛 플래시 |

- 용신 구슬과 기신 구슬은 둘 다 금테라 **"진짜 용신을 알아보는 눈"**이 실력 요소가 된다(기신은 테두리 안 한자가 다름).
- 용신이 하필 "나를 극하는 오행"(신강 사주의 관성 용신)이면 연출 문구: **"독이 약이 된다."**

## 3. 오늘의 일진 연동

게임 시작 시 **기기 로컬 날짜**의 일주(오늘 간지)를 계산해 내 사주와 비교. 해당 효과를 전부 합산.

| 판정 | 조건 | 효과 이름 | 효과 | 운세 점수 |
|---|---|---|---|---|
| 천간 생극 | 오늘 천간이 **나를 생함** | 엄마 찬스의 날 | 시작 HP +20 (오버힐) | +2 |
| | 같은 오행 | 라이벌 출몰의 날 | 어제의 나(고스트) 추월 시 +2000 | 0 |
| | 내가 생함 | 끼 폭발의 날 | 피버 충전 ×1.25 | +1 |
| | 내가 극함 | 재물운 떡상의 날 | 코인 가치 ×1.5 | +1 |
| | **나를 극함** | 시련의 날 | 상극 장애물 +30%, **액땜 점수 ×2** | -2 |
| 지지 | 오늘 일지 ↔ 내 일지 **육합** | 귀인 강림 | 시작 보호막 +1, 코인 ×1.2 | +2 |
| | **충**(정반대) | 충돌 주의보 | 장애물 밀도 +20%, 점수 ×1.3 | -2 |
| 천간합 | 甲己·乙庚·丙辛·丁壬·戊癸 | 천생연분 | 용신 구슬 출현 ×2 | +1 |

운세 등급: 합계 ≥4 **대길** 🌈 / ≥2 **길** ☀️ / ≥0 **평** ⛅ / ≥-2 **흉** 🌧️ / 그 미만 **대흉** ⛈️

- 흉한 날일수록 **액땜 목표 거리가 짧아져**(아래 5장) "흉한 날 한 판 = 액땜" 이라는 역설적 플레이 동기를 만든다.
- 시작 화면 문구 예: `🌧️ 오늘(壬寅일)의 운세: 흉 — 시련의 날 / 천생연분`

### 4-2. 텍스트 규칙

**사인(死因)** — 마지막 피격의 관계로 템플릿 선택 (`{X}`=장애물 오행, `{ME}`=내 일간)

| 관계 | 템플릿 |
|---|---|
| 상극 | `{X} 기운 부주의로 삼재 도달` · `{X}克{ME} — 상극 정면충돌` · `{X}의 기운을 얕보다 팔자 꼬임` |
| 식상 | `{X}에게 기 빨려 탈진` · `퍼주다 퍼주다 방전 ({ME}生{X})` |
| 비겁 | `동족상잔 — {X}끼리 박치기` · `거울 속의 나와 충돌` |
| 인성 | `엄마({X})한테 등짝 맞고 기절` · `과잉보호({X}生{ME})로 질식` |
| 재성 | `만만한 {X}에게 방심하다 역관광` · `재물({X})에 눈이 멀어 추락` |
| 출혈 DoT | `{X} 기운에 벌목당해 과다출혈` |

**액땜 한줄평**: ≥90 "올해 액운 선결제 완료" / ≥70 "큰 액은 막았다" / ≥40 "반타작. 오늘은 계단 조심" / 그 외 "액땜 실패… 한 판 더 뛰어서 갚으세요"

**공유 문구**: `[운명 피하기] 火일간 불꽃 폭주족 "화끈이" 440m 생존! 사인: 水克火 — 상극 정면충돌 / 액땜 56% 🔮`

### 4-3. 공유 UX

1. **공유하기** → 버튼 없는 카드 PNG 생성 → `navigator.share({files})`(모바일 인스타/카톡 시트)
2. 미지원 브라우저 → PNG 다운로드 + X(트위터) 인텐트 새 창
3. **이미지 저장** → PNG 다운로드만
4. **다시 달리기** → 같은 캐릭터로 즉시 재시작 (결과 카드 → 게임까지 1탭)

## 5. 계산 로직 & 공식

### 5-1. 오행 인덱스와 상생·상극

오행을 상생 순서로 번호 매긴다: **木0 → 火1 → 土2 → 金3 → 水4**

```
상생: a 가 b 를 생한다  ⇔  (a + 1) mod 5 = b     木→火→土→金→水→木
상극: a 가 b 를 극한다  ⇔  (a + 2) mod 5 = b     木→土→水→火→金→木

관계(me, other):  d = (other − me + 5) mod 5
  d=0 SAME(비겁)  d=1 I_GENERATE(식상)  d=2 I_CONTROL(재성)
  d=3 CONTROLS_ME(관성·상극)  d=4 GENERATES_ME(인성·상생)
```

예) 木(0) 일간 vs 金(3) 장애물 → d=3 → **상극**. 木 vs 水(4) → d=4 → **상생**.

### 5-2. 간이 만세력

| 기둥 | 공식 |
|---|---|
| 일주 | `JDN(율리우스 적일)` → `idx60 = (JDN + 49) mod 60`, 천간 = idx60 mod 10, 지지 = idx60 mod 12 (검증: 2000-01-01 = 戊午, 1900-01-01 = 甲戌) |
| 년주 | 입춘(2/4) 이전이면 전년도. `idx60 = (연도 − 4) mod 60` |
| 월주 | 12절기 평균 날짜로 월지 결정. 寅월 천간 = `(연간 mod 5) × 2 + 2` (월두법: 甲己→丙寅…), 이후 1달마다 +1 |
| 시주 | 시지 = `⌊(시+1)/2⌋ mod 12`. 천간 = `(일간 mod 5) × 2 + 시지` (시두법: 甲己→甲子…). 23시 이후는 다음 날 일주(조자시) |

> 절입일 당일 ±1일 오차 가능 → 정식 서비스는 한국천문연구원 절기 시각 테이블로 교체. 진태양시 보정(서울 약 -32분)은 옵션(`minuteOffset`).

### 5-3. 신강/신약 & 용신 (억부 간이판)

```
score = Σ (돕는 글자 ? +w : −w)       돕는 글자 = 비겁 또는 인성, 일간 자신은 제외
w: 월지 2.0, 일지 1.5, 나머지 1.0
score > 0  → 신강  → 용신 = {식상, 관성, 재성} 중 개수가 가장 적은 오행 (동률: 식상 > 관성 > 재성)
score ≤ 0  → 신약  → 용신 = 인성 (단, 인성이 이미 3개 이상이면 비겁)
기신 = 용신을 극하는 오행 = (용신 + 3) mod 5
```

### 5-4. 충돌 판정 순서 (`resolveCollision`)

```
충돌 발생
 ├─ 사망 상태 or 도화살로 비켜준 장애물 ─────────▶ 무시
 ├─ 피격 무적 중(피버 아님) ────────────────────▶ 무시
 ├─ 피버/용신버스터 중 ────────────────────────▶ 박살 (+150 / +300)
 ├─ 백호살 && rand < 0.30 ────────────────────▶ 박살 (+500)
 ├─ 재성(내가 극함) && rand < 0.20 ────────────▶ 박살 (+200)
 ├─ 보호막 > 0 ───────────────────────────────▶ 보호막 -1, 무적 부여
 └─ 피해 적용
      damage = round( 20 × 크기 × 관계배율 × 동족할인 × 피해배율 )
      상극이면 상태이상(土 과다면 속도저하 면역) + 상극 피격 +1
      HP ≤ 0 → 화개 부활 남았으면 부활, 아니면 사망(사인 기록)
```

- `피해배율 = 역마 1.2 × 백호 1.3` (보유 시 곱연산)
- 계산 예) 木 일간, 역마살 보유, 낮은 金 장애물(크기 1.2) → `20 × 1.2 × 2.0 × 1.2 = 57.6 → 58` + 출혈 3초(총 9)

### 5-5. 피버 게이지

```
게이지 += 아이템 기본 충전량 × 결핍보상(부재 오행이면 2) × 피버충전배율(끼 폭발 1.25 × 화개 1.3)
기신 구슬: 게이지 −30
게이지 ≥ 100 → 일반 피버 (게이지 0 리셋)
```

### 5-6. 오늘의 액땜 성공률

```
목표거리 = 3000m + 운세점수 × 300m          (흉한 날일수록 목표가 짧다)
액땜% = min(99,
          40 × min(1, 거리 / 목표거리)
        + min(30, 30 × 상극회피율 × 액땜배율)   상극회피율 = 회피 / (회피 + 피격), 기록 없으면 0.5; 시련의 날 배율 2
        + 15 × [용신버스터 1회 이상]
        + 15 × min(1, 최대콤보 / 50) )
```

100%는 없다(“운명은 완벽히 피할 수 없다”).

### 6-1. 연출 기믹 구현 메모

| 기믹 | 발동 | 구현 |
|---|---|---|
| **역마살 출장** | 30초마다 | 서울·파리·카이로·뉴욕·도쿄·하와이 중 직전과 다른 나라로 전환. 스카이라인 tileSprite(패럴랙스 0.25배) 텍스처 교체, 하늘/땅 색 변경, 화이트 플래시, "✈ 긴급 출장: 파리!" 배너. 역마살이 없으면 서울 고정 |
| **火 과다 아지랑이** | 20초마다 1초 | 카메라 미세 회전(±0.006rad)·줌 떨림 + 주황 오버레이 펄스. WebGL/Canvas 둘 다 동작 |
| **水 과다 물결** | 25초마다 2초 | 카메라 느린 회전(±0.02rad)·줌 + 파란 오버레이 |
| **水 과다 물보라** | 슬라이딩 중 낮은 장애물 접촉 | 피해 없이 통과 + 물방울 파티클, 4초 쿨다운(쿨 중엔 정상 피격) |
| **저스트 회피** | 장애물이 플레이어 x 구간에 들어오는 순간, 마지막 점프/슬라이딩 시작이 0.15초(無金 0.105초) 이내 + 통과까지 무접촉 | 누구나 +100·콤보+1. 金 일간은 +300 + 0.6초 슬로모(게임 dt·물리·트윈 timeScale 0.35) + 플래시 |
| **라이벌 고스트** | 비겁일 | 기기에 날짜별 최고 거리 저장, "오늘 이전의 가장 최근 날짜" 기록이 고스트. 15m 이내로 따라잡으면 반투명 분신이 앞에 보이고, 추월 시 넘어지며 +2000(점수 배율 적용). 기록이 없으면 300m "과거의 나(추정)" |
| **착지 경직** | 착지 순간 | 기본 0ms, 無土 50ms. 경직 중 점프 입력은 버리지 않고 경직이 끝나는 순간 실행(선입력 버퍼) |

- **점수 배율**: 역마살 ×1.8, 충 ×1.3 등 `scoreMult`는 모든 점수 획득(`addScore`)에 곱해진다. 기신 페널티(-200)만 예외.
- 플레이어 스프라이트는 발 기준(origin 0.5, 1)이라, 슬라이딩으로 scaleY가 바뀌어도 판정 바닥이 지면에 고정된다.
