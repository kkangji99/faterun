# 운명 피하기 — 기획 v0.3 (하늘에서 떨어지는 운명 피하기)

> 생일만 넣으면, 내 팔자대로 떨어지는 운명을 피한다.
> 목표: **3초 안에 이해되는 규칙 + 한 판 더 하고 싶은 손맛.** 사주는 양념.

## 규칙 (이게 전부)
- **손가락으로 좌우로 움직인다.** (PC: ← →)
- **내 색깔**(본캐 오행)이 떨어지면 → 친구. **먹으면 점수 + 콤보**
- **다른 색깔**은 전부 운명 → **피한다.** 맞으면 하트 -1 (하트 3개)
- **아슬아슬하게** 피하면 보너스 점수 + 콤보 + 럭키 게이지
- 게이지가 차거나 **럭키템(네잎클로버)**을 먹으면 **럭키타임 5초**: 닿는 건 전부 코인
- **짝퉁 럭키템(세잎)**은 게이지 0 + 점수 -300

위험을 무릅쓰고 스칠수록 점수가 커지는 구조라, 잘하는 사람은 일부러 아슬아슬하게 피한다.

## 떨어지는 운명: 오행마다 움직임이 다르다
외울 필요 없이 보면 익힌다.

| 오행 | 물체 | 움직임 |
|---|---|---|
| 🌱 나무 | 가시덩굴 | 땅에 `!` 표시 → 쑥 솟아오름 |
| 🔥 불 | 불똥 | 떨어진 뒤 내 쪽으로 데굴데굴 |
| 🪨 흙 | 바위 | 점점 빨라지며 쿵 |
| ⚔️ 쇠 | 가위 | 지그재그로 흔들리며 |
| 💧 물 | 물폭탄 | 바닥에서 펑 (주변까지 튐) |

- 운명 비율: **내 천적 3배**, 오늘 기운 센 오행 2배, 내 색깔은 운명으로 안 나옴
- 내 색깔 물체는 웃는 얼굴 + 반짝이, 운명은 심술궂은 얼굴

## 웨이브 (시간이 갈수록 빠르고 촘촘하게, 1분 30초에 최고 난이도)
| 웨이브 | 내용 |
|---|---|
| 친구 소나기 | 내 색깔 + 코인 (첫 4초는 무조건 이것 → 규칙을 몸으로 익힘) |
| 비 | 여기저기 랜덤 |
| 섞기 | 친구와 운명이 섞여서 (먹으러 가다 맞는 재미) |
| 벽 | 한 줄로 쏟아지는데 **한 칸만 비어 있음** → 빈칸으로! |
| 저격 | 천적이 ▼ 조준 후 내 머리 위로 빠르게 |

럭키템은 20초마다 보장.

## 사주가 하는 일 (양념)
| 게임 말 | 사주 말 | 효과 |
|---|---|---|
| 본캐 / 내 색깔 | 일간 | 캐릭터 + 먹는 색깔 |
| 천적 | 나를 극하는 오행 | 제일 많이 떨어지는 운명 |
| 럭키템 / 짝퉁 | 용신 / 기신 | 네잎·세잎 클로버 가운데 색 |
| 팔자 스킬 | 신살 | 🧳방랑벽(이동 ×1.3, 점수 ×1.5) · 💘인기쟁이(자석, 운명이 반해서 비켜감) · 🧘해탈 도사(1회 부활) · 🐯돌진 호랑이(30% 튕겨냄) · 🍀무난한 팔자(하트 +1) |
| 오늘의 운세 | 일진 | 오늘 기운 센 오행이 많이 떨어짐 + 하루 효과(하트·코인·럭키타임·점수) |
| 팔자 한 줄 요약 | 오행 과다/부재 | "쇠가 텅 빈, 방랑벽 있는 불꽃 폭주족" |

## 결과 카드 (1080×1920)
제목·운세 별점 → 본캐 + 한 줄 요약 → 피해요!(천적) / 먹어요!(내 색깔) / 럭키템 → 팔자 스킬 → **사인(死因)** → **오늘의 액땜 %** → 버틴 시간 · 아슬아슬 · 최고 콤보 → 다시 하기 / 저장 / 공유

- 사인 예: "하늘에서 떨어진 천적 물폭탄에 정수리를 맞고 꺼져버림"
- 액땜 %: 버틴 시간 40 + 아슬아슬 20 + 먹은 친구 20 + 최고 콤보 10 + 럭키타임 10 (최대 99)

```
src/rules.js      닿기·아슬아슬·아이템·럭키타임·사인·액땜 (순수 함수)
src/patterns.js   웨이브 생성기
src/RunScene.js   Phaser 게임 씬 (드래그 이동, 오행별 움직임, 원 충돌)
src/art.js        캐릭터·떨어지는 물체·아이템 그림 (캔버스)
src/sfx.js        효과음 (WebAudio 합성)
src/resultCard.js 결과 카드 + 저장·공유
src/saju/*        만세력 계산 (화면에 드러나지 않음)
```
